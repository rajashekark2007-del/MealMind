# MealMind Dashboard

An interactive canteen meal-planning and food-waste prevention dashboard prototype.

## Run locally
Open `index.html` in a browser. The dashboard loads Tailwind CSS, Chart.js, Font Awesome, and Google Fonts from CDNs, so an internet connection is needed for those assets.

## Deploy with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and this `README.md` to the repository root (or upload the ZIP contents).
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select your default branch (usually `main`) and the `/ (root)` folder, then save.
6. Wait for the Pages deployment to finish and open the published URL.

## Notes
- This is a front-end prototype; daily log entries are held in browser memory and are not saved to a backend/database.
- Forecasts and validation logs use sample data.
